Release 1.0.1.31: массовая выгрузка — заголовок при переключении DT/CF и корректное состояние кнопок после завершения (#92), лицензии — колонка «Пользователей» и узкие «Серийный номер»/«Модуль» (#83), тестовая копия — UTF-16LE-вывод rac, NUL в разборе и stdout через временный файл (#79)

- #92: заголовок окна массовой выгрузки обновляется при переключении типа выгрузки
  DT/CF (раньше продолжал показывать прежний тип); после завершения операции кнопки
  «Выполнить» и «Остановить» приводятся в корректное состояние — «Выполнить» снова
  активна, «Остановить» не остаётся «зажатой» (BatchOperationsWindow.xaml.cs,
  BatchOperationsWindow.Avalonia.cs, BatchOperationsViewModel).
- #83: количество пользователей лицензии выведено в колонку «Пользователей» через
  новое свойство LicenseCountText (RingLicenseService); парсер лицензий
  (RingLicenseParser) расширен вариантами распознавания «Количество пользователей»
  из реальных файлов *.lic; колонки «Серийный номер» и «Модуль» в таблице
  установленных лицензий сужены, чтобы «Пользователей» помещалась на экран
  (WPF и Avalonia — ServerMonitorWindow).
- #79: (а) вывод rac в UTF-16LE теперь распознаётся (ConsoleOutputDecoder);
  (б) NUL-символы вычищаются в RacOutputParser.ParseInfo; (в) сырой stdout команды
  rac журналируется в CM_RAC для диагностики; (г) «infobase info» при проблемах
  с перенаправлением вывода читается через временный файл
  (RacClient.TryRunViaFileRedirectAsync).
- Локализация: новые ключи (ru/en) для колонки «Пользователей» и сообщений rac.
- Тесты: Issue83ConsoleOutputDecoderTests (UTF-16LE-вывод), Issue83LicenseTabTests
  (колонка «Пользователей», LicenseCountText), Issue92BatchDumpTests (заголовок
  DT/CF, состояние кнопок после завершения), Release100127Tests обновлены под
  версию 1.0.1.31.
- Версия 1.0.1.30 -> 1.0.1.31 (csproj: Version/AssemblyVersion/FileVersion/
  InformationalVersion), CHANGELOG.md, README.md.
