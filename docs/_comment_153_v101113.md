Спасибо за проверку на 108 и точное описание — «индикатор сразу на двух строках,
щелчок открывает существующее окно, на вкладке “Запущенные” лишняя база»
подтвердилось. Это регрессия исправления 1.0.1.107.

Причина: `FindDirectOwners` возвращал **все** записи списка с одинаковым
подключением, а `MatchProcesses` привязывал один и тот же процесс сразу ко всем
ним. Поэтому обе записи получали `IsRunning`/`IsEnterpriseRunning`, обработчик
двойного щелчка видел у второй записи «Предприятие запущено» и активировал чужое
окно, а вкладка «Запущенные» показывала две строки для одной запущенной базы.

Что исправлено в **1.0.1.113** (Windows и Linux):

- добавлен `RunningInfobaseMatcher.SelectOwnerForProcess`: на один процесс
  выбирается ровно одна запись. Если в командной строке есть `/N`, выбирается
  запись с совпадающим эффективным пользователем Предприятия (регистр, пробелы и
  кавычки не важны); если `/N` нет — запись с авторизацией ОС или без явных
  учётных данных. При неоднозначности выбор детерминирован по ключу базы;
- `MatchProcesses` использует этот выбор, `FindOwner` остаётся только fallback
  при отсутствии прямых кандидатов; `FindDirectOwners` сохранён для диагностики;
- флаги `IsRunning`/`IsEnterpriseRunning`/`IsConfiguratorRunning` считаются по
  собственному списку процессов записи, а режим «Только запущенные» сравнивает
  состав по ключу базы, а не по `Id` (у баз без `Id` сравнение ломалось);
- активация существующего окна выполняется только для запущенной записи, а окна
  перечисляются с фильтром по учётной записи. Щелчок по второй записи запускает
  новый экземпляр под её учётными данными, а не поднимает чужое окно;
- тесты `Issue153SharedConnectionTests` переписаны под правильное поведение:
  процесс без `/N` — только запись с авторизацией ОС; `/N` — только запись с
  явными учётными данными; два процесса под разными учётками — по одному
  процессу на запись; проверены дубликаты, разные подключения, регистр/кавычки/
  пробелы и детерминированный fallback для «Запроса».

Пожалуйста, проверьте на сборке **1.0.1.113**: при запуске любой базы индикатор
должен появляться только у той строки, под чьей учётной записью запущен процесс;
щелчок по второй строке должен запускать новую базу под её учётными данными;
на вкладке «Запущенные» одна запущенная база — одна строка.
