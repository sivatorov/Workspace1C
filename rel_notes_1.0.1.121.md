## [1.0.1.121] — 2026-11-25

### Исправлено

- **Порядок в панели статусов (issue #168, Windows и Linux).**
  Информационные надписи (состояние синхронизации, индикатор загрузок и обновления)
  собраны в единую растягивающуюся область **слева**: при нехватке места текст обрезается,
  а полный текст доступен в подсказке. Версия программы с кнопкой и иконки управления
  закреплены **справа**. В Avalonia убрана фантомная колонка `downloadsPanel`, из-за
  которой содержимое панели смещалось.

- **Скачивание платформы: выбор раздела страницы загрузок (issue #167, Windows и Linux).**
  Добавлена галочка «Только моя разрядность»: фильтрация x64/x86 применяется только при
  включённой галочке (по умолчанию включена). Появился выбор **раздела** страницы
  загрузок — галочка и `ComboBox`, видимый при наличии разделов (`HasSections`). Выбор
  файла сохраняется между открытиями окна. Локализация ru/en.

- **Хранение паролей от баз: компактные диалоги (issue #163, доработка, Windows и Linux).**
  Диалог подтверждения шифрования стал узким (480/420/560, высота по содержимому,
  переносы строк), тексты `Secrets.*` сокращены и разбиты на строки, окно запроса пароля
  — 440/520. Функционал шифрования, выпущенный в 1.0.1.120, не менялся.

- **Linux: кнопка обновления в подвале (issue #166).**
  Значок обновления получил разрешаемую заливку (`ThemeBrushes.FromSpec("@AccentBrush")` /
  `"@SuccessBrush"`), прозрачный фон и `Cursor=Hand`. Значок больше не скрывается навсегда
  при отсутствии или сбое службы обновления, а сбои логируются без токенов.

- **Не спрашивает пароль при старте: размеры окон (issue #164, доработка, Windows и Linux).**
  Окно входа получило `SizeToContent="Height"`, `MinHeight 220`, строку профилей `Auto`
  (при одном профиле — 0), `ListBox.MaxHeight 280` и профиль `DialogWorkAreaPolicy.Login`.
  Окно блокировки — авто-высоту и профили `AppLock` (340/240/520) и `AppLockChange`
  (430/340/560) с клампом по рабочей области и экрану. Запрос пароля при старте,
  выпущенный в 1.0.1.120, сохранён.

- **Linux: правый клик на «Утилиты» (issue #159, доработка).**
  Иконка узла строится по геометрическому ключу (`DisplayIconGeometryKey`, цвет через
  `FromSpec`), вся строка узла кликабельна (прозрачный фон, `Cursor=Hand`, обработчик ПКМ),
  раскрыватель растянут на строку в темах Avalonia и WPF.

- **Linux: «Мои программы» — сохранение без исключения (issue #158, доработка).**
  Добавлен безопасный `TrySave` с записью в лог и сообщением пользователю; `OnClosing`
  больше не бросает исключение, окно закрывается штатно; «Отмена» работает через
  `Close()`. Новые ключи локализации `Launch.CustomPrograms.SaveFailed` /
  `SaveFailedTitle`.

### Тесты

- `Issue168StatusBarLayoutTests` — порядок и обрезка информационной области панели статусов.
- `Issue167PlatformDownloadSectionTests` — фильтр разрядности, выбор раздела, сохранение файла.
- `Issue163PasswordDialogLayoutTests` — размеры и переносы в диалогах паролей.
- `Issue166FooterUpdateIconTests` — заливка, прозрачность и видимость значка обновления.
- `Issue164LoginWindowSizeTests`, `Issue164AppLockWindowSizeTests` — размеры окон входа и блокировки.
- `Issue159UtilitiesContextMenuTests` — иконка узла, кликабельность строки и ПКМ.
- `Issue158MyProgramsSaveTests` — безопасное сохранение и закрытие окна «Мои программы».

### Что проверить

- **Панель статусов (#168):** при сужении окна информационные надписи обрезаются слева и
  показывают подсказку; версия и иконки управления остаются справа и не перекрываются;
  в Linux нет пустой «фантомной» колонки справа.
- **Скачивание платформы (#167):** с включённой галочкой «Только моя разрядность» видны
  только файлы своей разрядности, без неё — все; выбор раздела страницы загрузок
  показывает файлы выбранного раздела; выбранный файл сохраняется при повторном открытии.
- **Пароли (#163):** диалог подтверждения шифрования узкий, без обрезки текста, с
  переносами; окно запроса пароля компактное (440/520).
- **Обновление на Linux (#166):** значок обновления виден и кликабелен (`Cursor=Hand`) даже
  при отсутствии или сбое службы обновления; в логе нет токенов.
- **Окна входа и блокировки (#164):** окно входа подстраивает высоту под содержимое (без
  пустого места над полем пароля); окно блокировки без «кучи» пустого места под кнопками;
  при нескольких профилях список ограничен по высоте.
- **«Утилиты» на Linux (#159):** правый клик по любому месту строки узла открывает
  контекстное меню; иконка узла отображается в теме.
- **«Мои программы» на Linux (#158):** при ошибке сохранения окно не падает, показывается
  сообщение, «Отмена» закрывает окно штатно.

### Сборка

- Single-file сборки Windows (WPF) и Linux (Avalonia), версия **1.0.1.121**.
- Полный прогон тестов: **8256** тестов, **8256** пройдено, **0** падений,
  **0** пропущено (длительность 3 m 40 s).

Собранные артефакты (single-file, self-contained, версия `1.0.1.121`):

| Платформа | Файл | Размер | Версия |
|---|---|---|---|
| Windows x64 (WPF) | `dist/win-x64/Workspace1C.exe` | 81,7 МБ | `FileVersion` = `1.0.1.121` |
| Linux x64 (Avalonia) | `dist/linux-x64/Workspace1C` | 51,5 МБ | `1.0.1.121` (в релизе — `Workspace1C-linux-x64`) |

Windows-бинарь собирается штатным `build-windows-single-file.ps1 -Configuration Release`;
smoke-проверка `Workspace1C.exe --list` (код 0, `stderr` пуст) и подтверждение
`--license-info --json` → `"proModules": true`, `FileVersion` = `1.0.1.121`. Linux-бинарь —
кросс-сборкой `build-linux-single-file.ps1 -Configuration Release` (`-p:ForceLinux=true`,
linux-x64, `HasProModules=true`, строка версии `1.0.1.121` в бинаре); запуск и smoke-тест
Linux-бинаря выполняются в CI на `ubuntu-latest`.
