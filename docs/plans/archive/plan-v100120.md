## 4. Новый функционал (предложения, реализуемо в одном релизе)

1. **Экспорт диагностики в ZIP** (помощь потоку support — все issues решаются по логам):
   кнопка «Собрать диагностику» (Настройки/О программе) — упаковка `app-*.log`,
   `cm_modal_trace.log`, версии ОС/приложения/платформ 1С в один ZIP + путь в буфер обмена.
   Файлы: новый `Services/DiagnosticsBundleService.cs`, пункт в SettingsWindow.
2. **Расписание для массовой выгрузки DT/CF** (развитие #92): вкладка в
   [`SchedulerService`](Workspace1C/Services/SchedulerService.cs) + [`ScheduledTaskStore`](Workspace1C/Services/ScheduledTaskStore.cs):
   «Выгрузить выделенные в DT/CF» по расписанию, шаблон имени переиспользуется из
   [`BatchOperationsService`](Workspace1C/Services/BatchOperationsService.cs).
3. **Автотема «Как в системе»**: авто-выбор тёмной/светлой по ОС (Windows: реестр AppsUseLightTheme;
   Linux: [`LinuxDesktopEnvironment`](Workspace1C/Services/LinuxDesktopEnvironment.cs) prefers-dark).
   Файлы: `AppSettings`, `App.axaml(.cs)`/`App.xaml(.cs)`.
4. **Копирование строки подключения без пароля** в контекстном меню базы (частый запрос
   поддержки: передать строку коллеге) — `SensitiveDataMasker` уже есть, изменений мало.

_Кандидаты 1 и 2 — приоритетные (закрывают реальный поток обращений); 3 и 4 — по остатку времени._
