# Как купить и активировать ПРО

Пошаговая инструкция для версии **1.x** (включая 1.0.1.119). Политика лицензирования:
**публичное ядро 1.x остаётся бесплатным**, а новые функции 2.x открываются ключом
`major=1` в официальной сборке. Версии до 1.0.1.119 не переделываются.

> Цена — **2000 ₽**, лицензия **бессрочная в рамках major-версии** и привязана к одному
> компьютеру. Для 1.x ключ выпускается с `major=1`.

---

## 1. Где взять код компьютера

Код компьютера нужен, чтобы выпустить ключ именно для вашей машины. Его можно получить
тремя способами:

1. **Окно «Лицензия»**: меню «Утилиты» → «Справка» → «Лицензия…» (или клик по пункту 2.x
   с отметкой « · ПРО»). Код показан в блоке «Код компьютера», рядом — кнопка
   «Скопировать код».
2. **Командная строка**: `Workspace1C --license-info` — выводит редакцию, код компьютера
   и состояние ключа.
3. **«О программе»**: «Настройки» → вкладка «О программе» → блок «Лицензия» — там же
   строка «Код компьютера: …».

Если код не определяется, скопируйте текст ошибки из окна «Лицензия» и приложите его
к обращению.

---

## 2. Куда отправить код

Официальные контакты (личных платёжных реквизитов в приложении нет):

- **Telegram-канал**: <https://t.me/Workspace1C>
- **Issues репозитория**: <https://github.com/sivatorov/Workspace1C/issues>

В обращении укажите:

- код компьютера;
- название лицензии (организация или ФИО);
- версию программы (`1.x`, например `1.0.1.119`) и что нужен ключ **`major=1`**.

---

## 3. Оплата

- Стоимость — **2000 ₽**.
- Лицензия **бессрочная в рамках major-версии**: ключ `major=1` работает во всех
  выпусках 1.x; для 2.x потребуется отдельный ключ `major=2`.
- Оплата обсуждается с автором в Telegram-канале. После оплаты вы получаете
  лицензионный ключ.

---

## 4. Выпуск ключа для 1.x

Ключ выпускает автор с помощью утилиты `LicenseIssuer`:

```text
LicenseIssuer issue --machine <код компьютера> --owner "<владелец>" --major 1
```

`--major 1` — обязательное уточнение для 1.x (значение по умолчанию также равно 1).
Ключ начинается с `W1C2.` (это префикс формата, а не номер версии) и содержит `major=1`.

Ключ с `major=2` к версии 1.x **не подойдёт** — программа сообщит, что ключ выпущен для
другой версии.

---

## 5. Активация ключа

Два равнозначных способа:

1. **Окно «Лицензия»**: вставьте ключ целиком в поле «Лицензионный ключ» и нажмите
   «Активировать». Пробелы и переводы строк внутри ключа игнорируются.
2. **Командная строка**:
   ```text
   Workspace1C --activate "W1C2.…"
   ```

После успешной активации окно «Лицензия» обновляется **без перезапуска программы**:
редакция становится «ПРО», в заголовке появляется метка **★**, список функций
пересчитывается, кнопка «Купить» скрывается.

Удалить ключ с компьютера можно кнопкой «Удалить ключ» в окне «Лицензия».

---

## 6. Проверка

Убедитесь, что всё сработало:

- `Workspace1C --license-info` показывает редакцию «ПРО», владельца и `major=1`;
- в заголовке главного окна появилась метка **★**;
- в «Настройках» → «О программе» блок «Лицензия» показывает «Редакция: ПРО», владельца
  и данные ключа;
- в окне «Лицензия» функции 2.x отмечены как «доступна» (в официальной сборке), а не
  «требуется ключ».

Если сборка публичная (без модулей ПРО), новые функции 2.x останутся недоступны даже
с ключом — для них нужна официальная сборка со страницы Releases. Public core при этом
работает всегда.

---

## 7. Частые проблемы

| Проблема | Причина | Что делать |
|---|---|---|
| «Ключ выпущен для другого компьютера» | Ключ привязан к коду другой машины | Сверьте код компьютера в окне «Лицензия» и запросите перевыпуск |
| Ключ не подходит после переустановки ОС | Изменился код компьютера | Получите новый код и запросите перевыпуск ключа |
| «Ключ выпущен для версий 2.x и не подходит…» | Ключ `major=2` на версии 1.x | Запросите ключ с `--major 1` |
| «Ключ повреждён или изменён» | Ключ скопирован не полностью | Скопируйте ключ целиком, начиная с `W1C2.` |
| Функции 2.x всё равно недоступны | Публичная сборка без модулей ПРО | Скачайте официальную сборку из Releases |
| «Не удалось определить код компьютера» | Ограничения ОС/виртуализации | Приложите текст ошибки к обращению |

---

## 8. Что остаётся бесплатным

Публичное ядро 1.x доступно **без ключа**:

- мониторинг серверов и оповещения;
- команды Telegram-бота;
- MCP-сервер для ИИ-агентов (`--mcp`);
- миграция баз между кластерами 1С;
- тестовый контур (тестовая копия);
- массовая загрузка конфигурации `.cf` по списку баз.

Всё, чего нет в перечне ПРО, доступно всегда. Ключ открывает только новые функции 2.x
(конвейеры обслуживания, консоль запросов по базам, сравнение окружения, автотесты,
тренды производительности, журнал аудита, копии в S3) — и только в официальной сборке.
