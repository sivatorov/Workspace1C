🚀 Workspace 1C 1.0.1.117 — обновление выпущено

Что исправлено (issue #156):
• «Текущая сессия» стала разовым режимом: выбранные режим клиента и разрядность действуют только на ближайший запуск «1С:Предприятия» и после первого успешного запуска сами возвращаются в «Авто». Неудачный запуск и «Конфигуратор» разовый выбор не сбрасывают, настройки баз не меняются.
• В карточке «Текущая сессия» появилась «скрепка»: пока она нажата, выбранные значения сохраняются после запуска — до отжатия. Скрепка и значения не переживают перезапуск программы, после старта всегда «Авто».
• Паритет Windows и Linux: одинаковое поведение и оформление карточки в WPF и Avalonia, локализация на русском и английском.

Проверка: полный прогон — 8028 тестов, 0 падений, 0 пропущено.

Доступны сборки для Windows и Linux — один файл, установка .NET не требуется.
