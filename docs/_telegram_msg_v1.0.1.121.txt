🚀 Workspace 1C 1.0.1.121 — обновление выпущено

Что нового:

• Панель статусов: информационные надписи собраны слева с обрезкой и подсказкой, версия и иконки управления — справа; в Linux убрана фантомная колонка (#168).

• Скачивание платформы: галочка «Только моя разрядность» (по умолчанию включена) и выбор раздела страницы загрузок, выбор файла сохраняется (#167).

• Linux: значок обновления виден и кликабелен даже при сбое службы обновления (#166); правый клик по всей строке «Утилиты» (#159); «Мои программы» сохраняются без исключения (#158).

• Компактные диалоги паролей (#163) и окна входа/блокировки без пустого места (#164).

Доступны сборки для Windows и Linux — один файл, установка .NET не требуется.
