Реализовано в версии **1.0.1.8** (Windows и Linux):

**Массовая выгрузка в DT/CF из «Для выделенных…»** — как вы и просили:

1. В подменю **«Для выделенных (N)…»** контекстного меню добавлен пункт **«Выгрузить в DT\CF…»**.
2. Единое окно с:
   - **шаблоном имени файла** — токены `{Имя}` (имя базы) и `{Дата}` (по умолчанию `yyyy-MM-dd_HH-mm`); недопустимые символы санитизируются, при отсутствии шаблона — просто `имя.dt` / `имя.cf`;
   - **полем папки** с выбором каталога;
   - **переключателем DT / CF** (выгрузка конфигурации — через ibcmd `config dump`).
3. Шаблон и папка **сохраняются между сессиями** — при следующем открытии подставляются последние значения.
4. Прогресс — по базам, выполнение последовательное (как в существующих массовых операциях); для клиент-серверных баз выгрузка ibcmd требует профиль СУБД — при его отсутствии будет понятное сообщение.

Также доступно из меню «Утилиты» → «Операции» для работы по всему списку баз.

Покрыто тестами [`Issue92BatchDumpTests.cs`](Workspace1C.Tests/Issue92BatchDumpTests.cs) (токены шаблона, санитизация, коллизии имён, валидация).
