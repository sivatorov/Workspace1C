Release 1.0.1.9: доработки мастера «Развернуть тестовую копию» по issue #79

- #79 (Windows и Linux): убрана кнопка-дубль «Учётные данные ИБ для ibcmd…»
  внизу окна мастера (TestDeployWindow.cs, TestDeployWindow.Avalonia.cs) —
  она дублировала блок «Данные для выгрузки через ibcmd» и кнопку «Свойства
  исходной базы» вверху окна; связанные ключи локализации вычищены (ru/en);
- #79: вместо дублирующих профиль полей добавлена кнопка «Подставить из
  профиля СУБД» (по аналогии с «Подставить из базы») — заполняет поля СУБД
  формы (тип, сервер, база, пользователь, пароль) из профиля исходной базы
  окна «Резервные копии СУБД» (TestDeployViewModel.AutofillDbmsFromProfile);
  при отсутствии профиля — подсказка (TestDeploy.NoDbmsProfile); поля
  остаются редактируемыми вручную;
- #79: операция выполняется по значениям на форме — поля СУБД передаются
  в ibcmd как переопределение параметров подключения (TestDeployService →
  IbcmdService.DumpAsync с dbmsProfileOverride); при пустых полях формы
  используется сохранённый профиль, как раньше;
- #79: разовый сценарий без сохранённого постоянного профиля проходит
  пред-валидацию — TestDeployPlanner.Validate принимает либо сохранённый
  профиль СУБД, либо заполненные поля СУБД на форме; тексты подсказок
  TestDeploy.NeedDbmsProfile и TestDeploy.IbcmdCredentialsHint обновлены;
- тесты: Issue79TestDeployWindowTests — отсутствие удалённой кнопки-дубля
  и её ключей локализации, наличие кнопки «Подставить из профиля СУБД»,
  подстановка полей из профиля, пред-валидация разового сценария
  (с заполненными полями формы — проходит, с пустыми — понятная ошибка),
  значения полей формы попадают в сценарий; весь набор — 5250 тестов;
- версия 1.0.1.8 → 1.0.1.9 (csproj: Version/AssemblyVersion/FileVersion/
  InformationalVersion), CHANGELOG.md, README.md.
