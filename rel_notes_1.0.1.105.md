# Workspace 1C 1.0.1.105

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

### Исправлено

- **Меню «Утилиты»: у групп снова видны подписи (issue #146, Windows и Linux).**
  В 1.0.104 режим отображения группы по умолчанию был «Иконка», поэтому
  разделы «Обновления», «Приложение», «Справка» и другие группы показывались
  только значками. Теперь по умолчанию используется «С надписью»: в меню видны
  иконка и текст, как в остальных меню. Компоновки, сохранённые 1.0.104 с явным
  `DisplayMode: "Icon"`, однократно мигрируются на подписи (схема 4); явный
  выбор «Иконка» в новой схеме сохраняется. Новые группы, создаваемые в
  редакторе, тоже по умолчанию идут с подписью.

### Тесты

- Дополнен `Issue146UtilitiesMenuTests` (3 теста): дефолт «С надписью»,
  миграция схемы 3 с явным `Icon`, сохранение явного выбора в схеме 4.
- Полный прогон: **7706 тестов, все зелёные** (WPF-сборка); Linux/Avalonia
  собирается без ошибок.
