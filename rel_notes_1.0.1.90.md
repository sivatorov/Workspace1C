# Workspace 1C 1.0.1.90

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Иерархия действий в правой панели главного окна и честное disabled-состояние
  (аудит UI, пункт P1-3).**
  Раньше в правой панели одновременно соседствовали три разных веса у однотипных
  действий: «1С:Предприятие» — акцентная заливка, «1С:Стартер» — жёлтая заливка,
  «Конфигуратор» — только контур. Пользователь не понимал, что главное; «Выход»
  был красным, хотя красный в продукте означает удаление/ошибку; при пустом
  выборе кнопки запуска выглядели активными, хотя запускать было нечего.
  - «один акцент на экран»: акцентная заливка (`AccentBrush` + `TextOnAccentBrush`)
    осталась только у главного действия «1С:Предприятие»;
  - «Конфигуратор» — вторичная кнопка (фон карточки + контур), высота выровнена
    с «1С:Предприятием»;
  - «1С:Стартер» в группе «Мои программы» — нейтральная карточка без жёлтой
    заливки; `WarningBrush` оставлен только семантическим предупреждениям;
  - «Перейти по ссылке» — вторичная кнопка той же высоты, что и остальные;
  - «Выход» — нейтральный: текст и иконка цвета темы
    (`TextPrimary`/`TextSecondary`), без `ErrorBrush`/`#DC2626`;
  - при отсутствии выбранной базы (`SelectedInfobase == null`, включая выбор
    группы) кнопки «1С:Предприятие», «Конфигуратор» и «Перейти по ссылке»
    получают `IsEnabled = false`: opacity 0.5, обычный курсор, без hover-эффекта
    и с подсказкой «Выберите информационную базу»;
  - disabled-кнопки не получают фокус (штатное поведение WPF/Avalonia), порядок
    табуляции панели сохранён;
  - изменения симметричны в WPF ([`MainWindow.xaml`](Workspace1C/Views/MainWindow.xaml),
    [`MainViewModel.Display.cs`](Workspace1C/ViewModels/MainViewModel.Display.cs)) и
    Avalonia ([`MainWindow.Avalonia.Tree.cs`](Workspace1C/Views/MainWindow.Avalonia.Tree.cs),
    [`MainWindow.Avalonia.Controls.cs`](Workspace1C/Views/MainWindow.Avalonia.Controls.cs),
    [`UiMetrics.Avalonia.cs`](Workspace1C/Controls/UiMetrics.Avalonia.cs));
  - строки групп, навигация/вкладки, стили кнопок в диалогах, размеры иконок и
    отступы не затрагивались.
