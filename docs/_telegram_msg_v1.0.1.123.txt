Workspace 1C 1.0.1.123 — новый выпуск

Что исправлено:

1. Скачивание версии платформы (#167)
— галочка фильтра разрядности теперь слева от поля «Файл», без лишнего текста;
— строка выбора раздела страницы загрузок действительно появляется, когда на странице есть разделы;
— из подписей файлов убраны «Полный клиент (rar)», «Пакет deb» и подобные добавки — показываются только раздел, разрядность и имя файла;
— список сортируется по итоговой подписи.

2. Запуск ярлыком приложения, свёрнутого в трей (#164)
— проверка одиночного экземпляра выполняется до окна входа;
— повторный запуск активирует уже работающее окно без запроса пароля;
— при заблокированном приложении пароль по-прежнему требуется.

3. Редакторы на Linux (#159)
— раскрыватель дерева больше не «превращается в точку», клик работает по всей колонке;
— иконки узлов различимы во всех редакторах;
— четыре окна правки открываются по содержимому, без постоянного внешнего скролла; на маленьком экране клампятся по рабочей области.

4. «Мои программы» на Linux (#158)
— окно закрывается «Отменой», Esc, крестиком и после сохранения, в том числе после ошибки;
— одновременно открыто не более одного редактора;
— переименование сразу видно в списке;
— удаление программы не показывает необработанных ошибок и не трогает файлы иконок пользователя.

Все исправления реализованы и для Windows (WPF), и для Linux (Avalonia).
