## Issue #105: Доступные пункты контекстного меню для группы

### Описание

Просьба пересмотреть состав доступных (активных) пунктов контекстного меню  для группы.

Сейчас на глаз есть лишние, например:
1. Всё подменю "Очистить кеш"
Либо надо инструменты открывать с переданными базами для очистки, либо делать недоступным.
Но лучше передавать.
2. "Список выгрузок"
3. "Зарегистрировать COM-коннектор"
4. "Публикация на вёб сервере"
5. "Связать с конфигурацией"

А в идеале - не просто делать пункты недоступными для группы - а просто не показывать.
Если в подменю не осталось доступных пунктов - само подменю тоже не показывать.

- **подменю, в котором не осталось применимых пунктов, не показывается**; лишние разделители убираются;
- **подменю «Очистить кэш» для группы — по вашему предпочтению «лучше передавать»**: окно очистки кэша открывается с предвыбранными базами группы (включая вложенные);
- применимость задаётся в каталоге команд (`ContextMenuCatalog.IsGroupApplicable` + `ContextMenuResolver.FilterForGroup`), поведение одинаково в Windows и Linux.

Тесты: `Issue105ContextMenuGroupTests` (10).
