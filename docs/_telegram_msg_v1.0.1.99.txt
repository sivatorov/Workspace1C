🚀 Workspace 1C 1.0.1.99

Новая навигация: интерфейс разгружен, все функции сохранены.

• Меню «Утилиты» разложено по сценариям: «Серверы», «Обслуживание», «Инструменты», «Ещё». Внутри — короткие подгруппы, любая функция за 2–3 клика.
• Панель списка баз: ежедневные действия и четыре кнопки разделов вместо ряда из 15+ иконок. Очистка кеша, синхронизация с ibases.v8i, проверка доступности, тема, компактный режим и смена пользователя — в меню разделов.
• Убраны дубли: экспорт и импорт *.v8i остались только в «Инструменты» → «Списки баз».
• PRO-функции помечаются звёздочкой «*» и сноской «* — доступно в версии PRO»; при выборе без лицензии открывается окно с кнопкой «Купить».
• Сохранённые компоновки меню автоматически мигрируют на новую схему.

Windows: Workspace1C.exe
Linux: Workspace1C-linux-x64
