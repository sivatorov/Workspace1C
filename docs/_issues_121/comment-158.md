Здравствуйте! Спасибо за проверку на Linux.

Доработано в версии **1.0.1.121** — [релиз v1.0.1.121](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.121).
Пустая группа и строка в редакторе были исправлены в **1.0.1.120**; в 1.0.1.121 исправлено сохранение.

**Причина.** При ошибке сохранения «Мои программы» `OnClosing` бросал исключение, из-за чего окно не закрывалось штатно, а пользователь не видел причины. Кнопка «Отмена» также могла приводить к исключению.

**Что изменено:**

- добавлен безопасный `TrySave` с записью в лог и сообщением пользователю;
- `OnClosing` больше не бросает исключение — окно закрывается штатно;
- «Отмена» работает через `Close()`;
- новые ключи локализации `Launch.CustomPrograms.SaveFailed` / `SaveFailedTitle`.

Паритет WPF/Avalonia, локализация ru/en. Тест: `Issue158MyProgramsSaveTests`.

**Что проверить на 1.0.1.121:**

- при ошибке сохранения окно не падает, показывается сообщение с причиной;
- после ошибки окно закрывается штатно;
- «Отмена» закрывает окно без исключения.

Issue не закрываю — прошу подтвердить на 1.0.1.121 и написать здесь.
