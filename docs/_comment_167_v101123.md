Здравствуйте, 7OH! Спасибо за подробные замечания по диалогу скачивания платформы — все четыре пункта учтены.

Исправлено в версии **1.0.1.123** — [релиз v1.0.1.123](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.123).

**Причина.** Галочка фильтра разрядности стояла отдельной строкой с поясняющим текстом. Разделы страницы загрузок не определялись: парсер распознавал заголовки только по `<b>/<strong>`, а страница `version_files` размечает разделы иначе. В подписях файлов выводились «добавки» типа «Полный клиент (rar)», «Тонкий клиент (zip)», «Пакет deb», которые часто не соответствуют содержимому.

**Что изменено:**

- галочка фильтра разрядности перенесена **слева от заголовка поля выбора файла**, без дополнительного текста; назначение поясняет подсказка (ToolTip);
- исправлено определение разделов страницы загрузок: парсер распознаёт заголовки `<h1>…<h4>`, `<summary>`, `<caption>`, `<legend>`, элементы с классом `group`/`section`/`header`, а также известные названия разделов («Windows (64-bit)», «Linux (64-bit)» и т.п.);
- если разметки разделов нет, они синтезируются по семействам ОС и разрядности; строка выбора раздела появляется только при наличии разделов;
- из подписей убраны «Полный клиент (rar)», «Тонкий клиент (zip)», «Пакет deb» и подобные добавки;
- подпись собирается по правилам: без галочек — `Раздел - x64 - имя`; только разрядность — `Раздел - имя`; только раздел — `x64 - имя`; обе галочки — `имя`;
- список сортируется по итоговой строке.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue167PlatformDownloadSectionTests` (включая HTML-фикстуры заголовков и фолбэк).

**Что проверить на 1.0.1.123:**

- строка выбора раздела появляется, когда на странице есть разделы, и фильтрует список;
- галочка разрядности расположена слева от заголовка поля «Файл», без лишнего текста;
- в подписях файлов нет «Полный клиент (rar)», «Тонкий клиент (zip)», «Пакет deb» и т.п.;
- все четыре комбинации галочек дают ожидаемую подпись (`Раздел - x64 - имя`, `Раздел - имя`, `x64 - имя`, `имя`);
- сортировка списка идёт по итоговой строке.

Если раздела всё ещё нет — пришлите, пожалуйста, HTML страницы `version_files` или лог: разметка портала может отличаться от учтённых вариантов.
