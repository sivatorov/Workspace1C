🚀 Workspace 1C 1.0.1.119 — обновление выпущено

Что нового:

• Адаптивные окна (Windows и Linux): единая политика размеров — потолок 1200×800 DIP, отступ 48 DIP от рабочей области монитора, прокрутка только когда содержимое выше окна. На 1366×768@100 % и 1920×1080@125 % окно помещается целиком, нижние кнопки видны. Стартовые размеры уменьшены, длинные формы прокручиваются, кнопки закреплены вне прокрутки.

• ПРО: public core в 1.x по-прежнему бесплатен — мониторинг и оповещения, Telegram-бот, MCP-сервер, миграция баз между кластерами, тестовый контур, массовая загрузка .cf. Новые функции 2.x теперь видны в меню с отметкой « · ПРО»: без ключа пункт открывает окно «Лицензия» и не выполняет действие, с ключом major=1 в официальной сборке работает сразу. Добавлен пункт «Утилиты» → «Справка» → «Как купить ПРО…» и пошаговая инструкция docs/pro/HOW-TO-BUY-PRO.md.

• Документация: обновлены README и PRO-EDITION, добавлена инструкция по покупке и активации ПРО.

Проверка: полный прогон — 0 падений, 0 пропущено; число тестов зафиксировано в релизных заметках.

Доступны сборки для Windows и Linux — один файл, установка .NET не требуется.

Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.119
