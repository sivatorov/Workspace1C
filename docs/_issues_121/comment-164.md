Здравствуйте! Спасибо за точные замечания по размерам окон.

Доработано в версии **1.0.1.121** — [релиз v1.0.1.121](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.121).
Запрос пароля при старте был выпущен в **1.0.1.120**; в 1.0.1.121 исправлена раскладка окон.

**Причина.** Окно входа имело фиксированную высоту — над полем пароля оставалось пустое место, а при нескольких профилях список не ограничивался по высоте. Окно блокировки также резервировало лишнюю высоту под кнопками.

**Что изменено:**

- окно входа: `SizeToContent="Height"`, `MinHeight 220`, строка профилей `Auto` (при одном профиле — 0), `ListBox.MaxHeight 280`, профиль `DialogWorkAreaPolicy.Login`;
- окно блокировки: авто-высота, профили `AppLock` (340/240/520) и `AppLockChange` (430/340/560) с клампом по рабочей области и экрану.

Паритет WPF/Avalonia. Тесты: `Issue164LoginWindowSizeTests`, `Issue164AppLockWindowSizeTests`.

**Что проверить на 1.0.1.121:**

- окно входа подстраивает высоту под содержимое, над полем пароля нет пустого места;
- при нескольких профилях список ограничен по высоте;
- окно блокировки без «кучи» пустого места под кнопками;
- при малом экране окна клампятся по рабочей области.

Issue не закрываю — прошу подтвердить на 1.0.1.121 и написать здесь.
