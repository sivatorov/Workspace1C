# Workspace 1C 1.0.0.74

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

### Добавлено

- **Подстановки для сценариев: полная структура базы и быстрый редактор (issue #67,
  Windows и Linux)** — диалог «Выбрать…» показывает полную структуру базы 1-в-1 с
  картой подстановок, сгруппированную по секциям («Основные», «Подключение»,
  «Произвольные поля», «Платформа», «Дата»); добавлены производные ключи
  `%тэги%`/`%tags%`, `%дополнительныеполя%`/`%extrafields%`, алиас `%группа%`.
  Устранены сильные тормоза: контекст запуска платформы кэшируется (TTL-кэш каталогов
  установленных платформ + контекст один раз на окно редактора), живое превью
  пересчитывается с задержкой, а не на каждый символ. «База для примера» автоматически
  — база, из которой запущен сценарий. Для базы с версией 8.3.3 `%full_exe_name%`
  больше не подставляет новейшую 64-битную платформу. Покрыто тестами
  `ScriptTokenPickerViewModelTests`, `ScriptScenarioEditViewModelTests`,
  `ScriptPreviewPerfGuardTests`, `PlatformVersionCacheTests`,
  `OneCPlatformLocatorPlatformVersionTests`.

### Изменено

- **Миграция баз: прогресс, статусы при ошибке и имя группы (issue #41, Windows и
  Linux)** — полоса прогресса растянута на всю ширину окна; при ошибке переноса
  статусы приёмника обновляются автоматически, без ручного «Получить статусы»; новая
  группа приёмника именуется «Хост - Кластер (порт)» (порт — только если
  нестандартный), иначе папки «Локальный кластер» разных серверов не сливаются.
  Покрыто тестами `ClusterMigrationServiceTests`, `ClusterMigrationViewModelTests`,
  `Issue41WindowLayoutTests`.

- **Меню трея: каталог иконок как в «Утилитах» и применённая иконка (issue #62,
  Windows и Linux)** — набор иконок пользовательских групп меню трея расширен до
  общего каталога с редактором «Утилиты»; исправлен баг «выбрали — сохранили — иконка
  совсем другая»: WPF-адаптер передаёт выбранный ключ и цвет группы в пункт меню и
  рисует именно её. Покрыто тестами `TrayMenuIconCatalogTests`.

### Исправлено

- **Публикация на Apache: `Define` объявлены до `Include` (issue #63, Windows и
  Linux)** — парсер стал двухпроходным: сначала собираются все `Define` главного
  конфига и включаемых файлов, затем раскрываются `Include`/`DocumentRoot`/`Listen` —
  «имя файла с переменной, но без значения» и «подсказка без порта» устранены.
  Покрыто тестами `ApacheConfIncludeParserTests`, `ApacheInstanceDetectorTests`.

- **Тёмная тема: читаемые подписи полей форм (issue #61, Windows и Linux)** — введена
  единая кисть подписи полей формы `FormLabelBrush` (связана с первичным цветом текста
  темы) во всех четырёх темах; построители окон `WpfUi.Label`/`AvaloniaUi.Label`
  используют её вместо вторичной кисти, которая у пользовательских схем могла
  оставаться тёмной в тёмной теме. Покрыто тестами-стражами `ThemeFormLabelTests`,
  `Issue61DarkPaletteAuditTests`.
