Исправлено в версии 1.0.0.74 (Windows и Linux) по последним комментариям:

1. **Полный список полей структуры базы 1-в-1.** Диалог «Выбрать…» теперь содержит КАЖДЫЙ ключ карты подстановок (`BuildValueMap`) — «список доступных полей = структура базы в файле настроек»: добавлены производные ключи `%тэги%`/`%tags%`, `%дополнительныеполя%`/`%extrafields%`, алиас `%группа%` ([`ScriptParameterResolver.cs`](Workspace1C/Services/ScriptParameterResolver.cs)); список сгруппирован по секциям «Основные»/«Подключение»/«Произвольные поля»/«Платформа»/«Дата» с локализованными заголовками ([`ScriptTokenPickerViewModel.cs`](Workspace1C/ViewModels/ScriptTokenPickerViewModel.cs), окна WPF/Avalonia).
2. **Скорость: кэш вместо 25-секундных зависаний.** Резолвер контекста запуска и поиск каталогов установленных платформ кэшируются (TTL 5 минут, сброс при смене дополнительных путей поиска/инвалидации — [`PlatformVersionService.cs`](Workspace1C/Services/PlatformVersionService.cs)); окно редактора вычисляет контекст один раз на «Базу для примера», а живое превью пересчитывается с задержкой 300 мс — «пробел» больше не тормозит 2–3 секунды, первый вход в редактор не длится ~25 секунд (тесты-стражи `ScriptPreviewPerfGuardTests`, `PlatformVersionCacheTests`).
3. **Корректная платформа для `%full_exe_name%`.** Для базы с платформой 8.3.3 резолвер больше не подставляет новейшую 64-битную 8.5.4.1878: версия ищется и в «чужой» разрядности (8.3.3 — x86), и только при полном отсутствии — резерв «новейшая установленная» ([`OneCPlatformLocator.ResolveBinDirectory`](Workspace1C/Services/OneCPlatformLocator.cs)); добавлены тесты с временными раскладками платформ `OneCPlatformLocatorPlatformVersionTests`.
4. **«База для примера» = база запуска.** Если сценарий запущен для конкретной базы (F5/контекстное меню) и вы открыли его правку из окна выбора — «База для примера подстановок» заранее подставлена именно она; из «Утилит»/без выделения — первая в списке (окна редактора WPF/Avalonia принимают `initialBase`).

Локализация ru/en (секции диалога); добавлены/расширены юнит-тесты `ScriptTokenPickerViewModelTests`, `ScriptScenarioEditViewModelTests`, `ScriptPreviewPerfGuardTests`, `PlatformVersionCacheTests`, `OneCPlatformLocatorPlatformVersionTests`.
