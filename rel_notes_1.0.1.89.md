# Workspace 1C 1.0.1.89

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

- **Строки групп в списке баз — спокойный пастельный фон вместо насыщенной
  заливки (аудит UI, пункт P1-2).**
  Раньше строка группы заливалась насыщенным цветом (синий, зелёный, красный) с
  белым текстом: в одном списке одновременно виднелись 3–4 яркие полосы, красная
  строка неотличима по восприятию от семантического «ошибка/опасность», зелёная
  конкурировала с акцентом темы, а белый текст не гарантировал контраст для
  пользовательских цветов.
  - фон строки — цвет группы, смешанный с `ContentBackground` темы в пропорции
    14 % (`GroupRowBackgroundHex`, рекомендованный диапазон 12–16 %): цвет группы
    узнаваем, но больше не конкурирует с семантическими цветами;
  - слева — вертикальная полоса 3 px исходным цветом группы
    (`HeaderStripeBrush`): идентичность выбранного пользователем цвета сохранена;
  - текст — `TextPrimary` темы, а при контрасте ниже 4.5:1 — WCAG-фолбэк
    чёрный/белый (`GroupRowTextHex`), поэтому текст читаем на пастели для любых
    пользовательских цветов, включая жёлтый;
  - hover — та же пастель с долей 24 % (`HeaderHoverBrush`), выделение осталось
    акцентной рамкой: ни hover, ни выбор не превращают строку в сплошную заливку;
  - кисти вычисляет `ThemeManager` обеих платформ из цвета группы и текущей
    схемы, а узлы дерева уведомляют привязки по `ThemeChanged` — смена темы
    перекрашивает строки сразу, без перезапуска;
  - изменения симметричны в WPF ([`MainWindow.xaml`](Workspace1C/Views/MainWindow.xaml),
    [`GroupNodeViewModel.cs`](Workspace1C/ViewModels/GroupNodeViewModel.cs)) и
    Avalonia ([`MainWindow.Avalonia.Tree.cs`](Workspace1C/Views/MainWindow.Avalonia.Tree.cs),
    [`GroupNodeViewModel.Avalonia.cs`](Workspace1C/ViewModels/GroupNodeViewModel.Avalonia.cs));
  - пикер цвета группы не менялся: в списке выбора группы чип остаётся исходным
    цветом (`HeaderStripeBrush`), поэтому выбор цвета по-прежнему нагляден;
    правая панель действий, стили кнопок, размеры иконок, отступы, навигация и
    вкладки не затрагивались.

## Тесты

- Добавлен `GroupRowAppearanceTests`:
  - (а) фон строки группы — смесь с фоном темы, а не исходный насыщенный цвет
    (точная формула 14 %, проверка диапазона 12–16 %, hover насыщеннее покоя, но
    остаётся пастельным);
  - (б) контраст текста ≥ 4.5:1 для красного, зелёного, синего, жёлтого и
    фиолетового на светлой/тёмной, Material и Windows XP поверхностях, включая
    фолбэк при нечитаемом `TextPrimary`;
  - (в) полоса использует исходный цвет группы (включая нормализацию `#RGB` и
    `#AARRGGBB`), плюс source-гварды WPF/Avalonia и пикера групп.
- Всего тестов: **7386**, все зелёные.
