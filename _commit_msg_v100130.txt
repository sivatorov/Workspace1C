Release 1.0.1.30: лицензии — чистое окно деталей без дублирующего блока полей (#83), тестовая копия — автоподстановка СУБД для кластерных ИБ через «infobase info» (#79), массовая выгрузка — «Стоп» гасит 1cv8, блокировка сеансов отключена для Конфигуратора, «session terminate» без кредов ИБ (#92)

- #83: окно деталей лицензии приведено к финальному виду — убраны ВСЕ распознанные
  поля (дублирующий блок), остаются только строка «Файл лицензии» (полный путь к *.lic)
  и оригинальное содержимое файла как есть; таблица «Установленные лицензии» не изменилась,
  парсер для таблицы не тронут — правится только формирование текста окна
  (RingLicenseService).
- #79: автоподстановка СУБД для кластерных ИБ не срабатывала — rac 8.5.4 в
  «infobase summary list» отдаёт пустые поля СУБД. Данные теперь гарантированно берутся
  из «infobase info», которая выполняется с перебором форматов аргументов «--cluster»
  (в т.ч. по имени кластера и порту менеджера) до успешного результата; при неудаче
  остаётся понятное сообщение с причиной и ручной блок «Данные СУБД источника»
  (RacClient, ClusterInfobaseCredentialsResolver).
- #92: «Стоп» не гасила процесс 1cv8 — лаунчер порождал дочерний процесс, поиск теперь
  идёт по WMI (командная строка DESIGNER с сужением по outputPath), реальные процессы
  1cv8/1cv8x64 завершаются, окно разблокируется (OneCLauncher.DesignerBatch,
  BatchOperationsViewModel).
- #92: опция «Блокировка начала сеансов» несовместима с движком Конфигуратора —
  отключается и не применяется (иначе /DumpIB не входит в базу «Начало сеанса
  запрещено»); снятие блокировок после операции выполняется даже при отмене
  (BatchOpsPreparationService, BatchOperationsWindow).
- #92: при ошибке разбора «--infobase-user=…» на rac 8.5.4 «session terminate»
  автоматически повторяется без кредов ИБ (RacClient).
- Локализация: новые ключи (ru/en) для сообщений резолва СУБД и остановки процессов.
- Тесты: BatchOpsPreparationServiceTests (блокировка сеансов для Конфигуратора, снятие
  при отмене), ClusterInfobaseCredentialsResolverTests (резолв через «infobase info»
  с перебором «--cluster»), RacClientTests (session terminate без кредов ИБ),
  Release100127Tests / Release100129Tests / Issue128BatchEngineLicenseRacTests обновлены
  под версию 1.0.1.30.
- Версия 1.0.1.29 -> 1.0.1.30 (csproj: Version/AssemblyVersion/FileVersion/
  InformationalVersion), CHANGELOG.md, README.md.
