Здравствуйте, 7OH! Спасибо за скриншоты и точное описание — оба дефекта подтвердились.

Исправлено в версии **1.0.1.120** — [релиз v1.0.1.120](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.120).

**Причина.** В тёмной теме строка «Учётная запись ИТС» выводилась обычным `TextBlock` без явного цвета, а у `TextBox` папки загрузки не было явных кистей и рамки. Итоговое имя файла формировалось с префиксом выбранной версии, хотя в логе показывалось исходное имя.

**Что изменено:**

- поля «Учётная запись ИТС» и «Папка загрузки» получили читаемые кисти (`TextPrimaryBrush`), фон, рамку (`BorderBrushColor`) и отступы; строка учётной записи обёрнута в `Border`;
- имя файла сохраняется без префикса версии — например `server64_8_5_1_1621.zip`; версия используется только если имя пустое, дублирование префикса исключено;
- лог, интерфейс и имя на диске теперь совпадают;
- докачка и обработка конфликтов имён не изменились.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue162PlatformDownloadTests`.

**Что проверить на 1.0.1.120:**

- тёмная и светлая темы: оба поля читаемы, у полей есть рамка;
- при скачивании файл сохраняется под именем из лога, без префикса версии.
