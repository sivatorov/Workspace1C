## [1.0.1.116] — 2026-11-24

### Исправлено

- **Окно «Правка контекстного меню»: пояснение вынесено из зоны прокрутки
  (issue #146, Windows и Linux).** Поясняющий текст больше не лежит внутри
  `ScrollViewer`: он закреплён внизу через `DockPanel` с `DockPanel.Dock="Bottom"`,
  а прокручивается только панель операций. Поведение совпадает с остальными тремя
  редакторами («Утилиты», «Меню трея», «Мои программы»); изменения продублированы
  в WPF- и Avalonia-версиях окна.

- **Высоты окон правки меню приведены к минимально необходимой (issue #146,
  Windows и Linux).** Для всех четырёх окон `Height = MinHeight`: «Утилиты» — 825,
  «Мои программы» — 760, «Меню трея» — 855, «Контекстное меню» — 685 DIP. Окна
  открываются сразу на этой высоте без завышенного запаса, прокрутка включается
  только как аварийный режим. Кламп по рабочей области сохранён
  (`MaxHeight = workArea − 48`): на маленьком экране верхняя граница побеждает.

- **Пункты и разделители можно вынести на верхний уровень панели инструментов
  (issue #146, Windows и Linux).** Пункт на верхнем уровне отображается кнопкой
  только с иконкой и подсказкой, разделитель — вертикальной чертой между кнопками;
  порядок сохраняется в компоновке. Панель больше не обрезает элементы (`WrapPanel`),
  а перенесённые в корень пункты и разделители не теряются.

- **«Инспектор процессов 1С» стал обычным пунктом меню «Утилиты» (issue #146,
  Windows и Linux).** По умолчанию он размещён на верхнем уровне; жёстко зашитая
  кнопка `ProcessInspectorButton` и её разделитель убраны с панели инструментов
  (как ранее «Очистка кеша» в 1.0.1.99). Горячая клавиша `Ctrl+Alt+I` сохранена.
