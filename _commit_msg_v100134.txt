Release 1.0.1.34: разбор вывода rac в «Развернуть тестовую копию» — NUL/BOM-нормализация, русские ключи полей, пароль СУБД (#79); массовая выгрузка DT/CF — движок «Конфигуратор» без rac-подготовки (#92)

- #79: при разборе серверной инфобазы (rac infobase info) у пользователей
  с rac 8.5.4 вывод приходил в UTF-16LE с NUL-байтами и/или с локализованными
  (русскими) ключами полей — парсер возвращал пустые значения при валидном
  выводе rac:
  - зачистка '\0'/BOM (\uFEFF) вынесена в единую точку декодирования
    (ConsoleOutputDecoder.SanitizeDecodedText) — чинит всех потребителей
    (rac, ibcmd, ring) без дублирования Replace("\0", …); в RacOutputParser
    добавлена та же защита в LooksLikeKeyValueOutput/TryParseKeyValueBlocks;
  - поддержка русских (локализованных) ключей полей вывода rac:
    «информационная база», «имя», «субд», «сервер бд», «имя базы данных»,
    «пользователь бд», «описание», «локаль», «блокировка начала сеансов»,
    «блокировка регламентных заданий»; алиасы применяются только когда
    английский ключ не найден/пуст, добавлена эвристика перезакодировки
    cp1251→cp866 для mojibake-ключей;
  - креды СУБД из полей мастера «Данные СУБД источника» подмешиваются в
    rac-профиль при разборе инфобазы (TestDeployService): rac-значения
    приоритетны, ручные поля заполняют только пустые (пароль всегда пуст) —
    ibcmd больше не падает на авторизации СУБД (sa+пароль при пустом пароле
    из профиля rac);
  - fixture-тесты на реальном выводе rac: UTF-16LE с BOM и без, NUL-текст,
    русские ключи, значения в кавычках, разделитель « : », merge пароля).
- #92: фаза «Перед операцией» (завершение сеансов/блокировки через rac)
  больше не запускается для выгрузки через движок «Конфигуратор» — rac для
  этого движка не требуется; при попытке включить rac-подготовку в журнал
  пишется предупреждение, выгрузка продолжается
  (BatchOperationsViewModel). rac-опции подготовки (завершение сеансов,
  блокировка сеансов) деактивируются при выборе движка «Конфигуратор» на
  обеих платформах (Windows/Avalonia) с подсказкой
  (BatchOperationsWindow.xaml.cs / BatchOperationsWindow.Avalonia.cs).
- Тесты: новые Workspace1C.Tests/Issue79RacInfoFixtureTests.cs (fixture
  racinfo.txt: UTF-16LE/BOM/NUL/русские ключи/merge пароля) и
  Issue92BatchDesignerPreparationTests.cs (rac-подготовка не блокирует
  выгрузку движком «Конфигуратор», деактивация rac-опций).
