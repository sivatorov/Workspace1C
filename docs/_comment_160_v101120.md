Здравствуйте, 7OH! Спасибо за описание сценария — он позволил точно локализовать причину.

Исправлено в версии **1.0.1.120** — [релиз v1.0.1.120](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.120).

**Причина.** На X11 фокус мог оставаться в родительском окне, а `ModalWindowBase` по ESC закрывал родителя — вместе с ним закрывались и дочерние диалоги. В итоге одно нажатие ESC закрывало три окна.

**Что изменено:**

- ESC закрывает только верхний по Z-порядку диалог;
- если есть видимое дочернее окно, родитель не закрывается, а дочернее активируется;
- главное окно закрывает ровно один верхний диалог;
- добавлена трассировка `ModalCloseTrace` для диагностики маршрутизации ESC.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue160EscapeRoutingTests`.

**Что проверить на 1.0.1.120:**

- настройки → структура → редактор меню: ESC закрывает только редактор;
- повторный ESC закрывает структуру, затем настройки — по одному окну за нажатие.
