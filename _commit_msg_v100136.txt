Release 1.0.1.36: «Развернуть тестовую копию» — загрузка .dt в новую пустую базу без ошибки «Пользователь ИБ не идентифицирован» (#79)

- #79: на шаге «Загрузка в копию» /RestoreIB запускался с учётными данными,
  унаследованными от исходной базы (и/или общей авторизации приложения), — но
  в только что созданной пустой базе пользователей ИБ ещё нет, поэтому платформа
  отвечала «Пользователь ИБ не идентифицирован» и показывала своё модальное
  окно (репорт 7OH: «причём дважды окно было»). Теперь для новой базы загрузка
  выполняется БЕЗ ключей /N//P: подавляющий credential формирует
  TestDeployService.BuildRestoreCredential(isNewBase) — пустые User/Password
  при UseInfobaseAuth == false дают пустую строку авторизации в
  RunDesignerBatch (ветка одинакова в WPF и Linux-лаунчерах). После успешной
  загрузки пользователи приходят из .dt, и наследованные креды источника снова
  работают для последующих шагов (регламентные задания и маркеры). Для
  обновления существующей копии поведение не изменилось — авторизация берётся
  из записи базы/общей авторизации.
- Тесты: RestoreCredential_NewBase_SuppressesAuth,
  RestoreCredential_ExistingBase_KeepsBaseAuth,
  RestoreCredential_SuppressedCredential_ProducesNoAuthArgs
  (Issue79TestDeployWindowTests.cs).
- Версия 1.0.1.35 -> 1.0.1.36 (csproj: Version/AssemblyVersion/FileVersion/
  InformationalVersion), CHANGELOG.md, README.md.
- Служебные файлы релиза: _build_v100136.ps1, commit-сообщение, план релиза,
  отчёт по issues (_issues_to_work_new.md, _issues_open_new.json,
  _collect_issues_work_new.ps1).
