Release 1.0.1.28: массовая выгрузка DT/CF — реактивный заголовок, многострочные подсказки и переключатель движка ibcmd/Конфигуратор (#92), резолвер СУБД — таймаут 90 с и повтор rac (#79), лицензии — все каталоги *.lic и полное окно деталей (#83)

- #92: заголовок окна массовой выгрузки не менялся при переключении DT/CF.
  Реакция UI переведена с событий радиокнопок (ненадёжны при программной установке
  и восстановлении вида из настроек) на PropertyChanged от BatchOperationsViewModel.Kind
  → UpdateKindDependentUi (BatchOperationsWindow.xaml.cs, BatchOperationsWindow.Avalonia.cs);
  заодно исправлена стартовая подсказка при открытии окна на CF — тернарник в конструкторе
  показывал подсказку выгрузки в .dt до первого переключения.
- #92: подсказка «Выгружать и запущенные базы» не переносилась — строковый ToolTip заменён
  на многострочный (TextBlock c TextWrapping, MaxWidth=360) на обеих платформах; то же
  для подсказки поля «Пароль пользователя СУБД».
- #92: переключатель движка выгрузки «ibcmd / Конфигуратор» (пожелание aepkugesi).
  Движок «Конфигуратор» (пакетный запуск 1cv8 /DumpIB|/DumpCfg через
  OneCLauncher.RunDesignerBatch) не требует пароля СУБД — авторизуется из свойств базы;
  при нём поля СУБД скрываются, опция «Выгружать и запущенные базы» не применяется
  (Конфигуратору нужен монопольный доступ к файловой базе), выбор запоминается
  в AppSettings, кнопка «Остановить» гасит процесс 1cv8. Загрузка .cf по-прежнему
  только через ibcmd.
- #79: мастер «Развернуть тестовую копию» не вычитывал свойства базы — все команды rac
  обрезались CommandTimeout=30 с (холодный rac/загруженный сервер не укладывался,
  RacClientException глотался резолвером → «база не найдена»). «infobase summary list»
  и «infobase info» в ClusterInfobaseCredentialsResolver выполняются с таймаутом 90 с,
  первая неудачная попытка повторяется автоматически (по образцу импорта из кластера,
  issue #25) — только для таймаутов/стартовых сбоев rac, ошибки прав не повторяются;
  сообщение о таймауте в журнале содержит фактическое число секунд.
- #83: «Серверы 1С → Лицензии», сообщение «Файл не найден» залипало в статусе —
  сообщение от клика по «Модуль» теперь временное (6 с), затем восстанавливается
  прежний статус вкладки.
- #83: пустая таблица лицензий — поиск *.lic расширен: раньше читался только первый
  существующий каталог (%ProgramData%\1C\1Cv8\licenses); теперь обходятся все места
  хранения 1С — добавлены %ProgramData%\1C\licenses и пер-пользовательские
  %LOCALAPPDATA%\1C\1cv8\licenses, %APPDATA%\1C\1cv8\licenses (дедупликация по имени
  файла) (RingLicenseService).
- #83: окно деталей лицензии показывало только имя файла — при сбое чтения в деталях
  видна причина («файл не прочитан (тип): …», BuildReadableDetails даёт текст вместо
  пустой строки); окно деталей показывает распознанные поля И полное содержимое файла
  лицензии многострочно (раньше — одну строку, обрезанную на 400 символов); парсер *.lic
  распознаёт компактные даты вида 20260907085731.
- Тесты: Issue128BatchEngineLicenseRacTests (движок Конфигуратор в массовой выгрузке,
  таймаут/повтор rac в резолвере, каталоги лицензий, парсер *.lic), Release100127Tests
  обновлён под версию 1.0.1.28 и новый текст BuildReadableDetails.
