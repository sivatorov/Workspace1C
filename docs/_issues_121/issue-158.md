### sivatorov @ 2026-11-25T16:49:39Z

Здравствуйте, 7OH! Спасибо за проверку на Linux и точные скриншоты.

Исправлено в версии **1.0.1.120** — [релиз v1.0.1.120](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.120).

**Причина.** Группа «Мои программы» скрывалась целиком при пустом списке; для шестерёнки использовался ключ `IconCog`, которого нет в наборах иконок, поэтому откат давал иконку папки; в шаблоне редактора возникал `NullReferenceException`; редактор не получал привязку `Programs` и не видел добавленную программу.

**Что изменено:**

- пустая группа «Мои программы» теперь видна: заголовок, подсказка «Добавьте программу» и кнопка настроек;
- вместо иконки папки — шестерёнка (`IconSettings`, есть во всех наборах);
- устранён `NullReferenceException` в шаблоне редактора, извлечение иконки исполняемого файла больше не бросает исключение;
- строка программы видна в редакторе: привязка `Programs` синхронизирована с общим хранилищем, после сохранения список перечитывается.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue158CustomProgramsLinuxTests`.

**Что проверить на 1.0.1.120:**

- пустой список программ — видна группа с кнопкой настроек и подсказкой;
- добавление `/usr/bin/mc` проходит без ошибки, в меню появляется иконка программы;
- в редакторе отображается строка добавленной программы.

Issue не закрываю — прошу подтвердить на 1.0.1.120 и написать здесь.
