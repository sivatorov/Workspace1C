### #63 — Доработка публикации баз (автор 7OH, comments=29, последний: 7OH @ 2026-10-30T08:37:19Z)

**Суть проблемы:** Публикация на веб-сервере не находит Apache-инстансы с отдельными конфигами (`httpd27.conf`): в логах все службы (`Apache2.4`, `Apache2.4_51`, `Apache2.4_54`) показывают один и тот же конфиг `c:\Apache\Apache24\conf\httpd.conf` и `ImagePath="c:\Apache\Apache24\bin\httpd.exe" -k runservice` — без параметров `-d`/`-f`. Файл алиасов (`1c8Aliases27.conf`) не появляется в списке webinst, публикация не работает.

**Контекст:** Дважды исправляли (1.0.1.2 — синтетический инстанс из конфига [`WebPublishService.BuildInstanceFromConf`](Workspace1C/Services/WebPublishService.cs); 1.0.1.4 — извлечение `-d`/`-f` из `ImagePath` в [`ApacheInstanceDetector`](Workspace1C/Services/ApacheInstanceDetector.cs), сохранение `RawCommandLine`). Пользователь: **«Всё по прежнему»**.

**Последние чужие комментарии (7OH):**
> Всё по прежнему
> Лог: `инстанс Apache найден: служба=Apache2.4, конфиг=c:\Apache\Apache24\conf\httpd.conf, ServerRoot=c:\Apache\Apache24, ImagePath="c:\Apache\Apache24\bin\httpd.exe" -k runservice` — то есть `ImagePath` БЕЗ `-d`/`-f`.

> На всякий случай уточню пример, где параметры в винде лежат
> `HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Apache2.4\Parameters\ConfigArgs`

**На что ориентироваться при исправлении:**
- Ключевая подсказка: параметры `-d`/`-f` у Apache-службы лежат НЕ в `ImagePath`, а в параметрах службы: **`HKLM\SYSTEM\CurrentControlSet\Services\<имя_службы>\Parameters\ConfigArgs`** (REG_MULTI_SZ, построчно: `-d`, `c:\Apache\Apache24`, `-f`, `conf\httpd27.conf`). Пользователь ранее приводил и вариант строки запуска службы: `-d c:\Apache\Apache24 -f conf\httpd27.conf`.
- В [`ApacheInstanceDetector.cs`](Workspace1C/Services/ApacheInstanceDetector.cs) нужно читать `ConfigArgs` через реестр (`Microsoft.Win32.Registry`, подойти и через `Registry.LocalMachine.OpenSubKey(@"SYSTEM\CurrentControlSet\Services\Apache2.4\Parameters\ConfigArgs")`), а не полагаться только на `ImagePath` из `QueryServiceConfig` — `ImagePath` содержит только `-k runservice`.
- Относительный `-f conf\httpd27.conf` резолвить относительно `-d`/ServerRoot.
- Сохранить/обновить лог `RawCommandLine`/`ConfigArgs` в лог CM_PUBLISH, чтобы пользователь мог проверить.
- Проверить fallback-поиск алиасов по суффиксу имени конфига в [`WebPublishViewModel.cs`](Workspace1C/ViewModels/WebPublishViewModel.cs) (`1c8Aliases27.conf` от `httpd27.conf`).
- Юнит-тесты: парсер `ConfigArgs` (в т.ч. незакрытые кавычки, относительный `-f`).
