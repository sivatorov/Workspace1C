Здравствуйте, 7OH! Спасибо за три точных замечания — все учтены.

Исправлено в версии **1.0.1.120** — [релиз v1.0.1.120](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.120).

**Причина.** Пароль учётной записи запрашивался не во всех случаях: при одной защищённой записи вход пропускался. В заголовке не было переменной с именем активной записи, а окно разблокировки показывало обезличенное «Пароль».

**Что изменено:**

- пароль учётной записи запрашивается при старте, в том числе когда защищённая запись одна;
- при одной записи список скрывается — остаются заголовок и поле пароля;
- подпись поля — «Пароль учётной записи **Имя**» (имя выделено жирным) и подсказка;
- в суффикс заголовка добавлена переменная `%app_user%`, подставляющая имя активной учётной записи; подсказка в настройках обновлена.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue164AccountPasswordPromptTests`, `TitleSuffixResolverTests`.

**Что проверить на 1.0.1.120:**

- старт с защищённой учётной записью — пароль запрашивается, без него вход невозможен;
- `%app_user%` в суффиксе заголовка подставляет имя активной записи;
- в окне разблокировки видно имя учётной записи.

Issue не закрываю — прошу подтвердить на 1.0.1.120 и написать здесь.
