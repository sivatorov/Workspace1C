## Хуки в публичном коде для ПРО-модулей

ПРО-модуль не может менять публичные окна напрямую, поэтому публичный код даёт
несколько точек расширения (добавляются в ветках 5–9 по мере надобности):

- `ProMenu.Register(UtilitiesMenuItem item, Action<object?> execute)` — пункт меню
  «Утилиты» из модуля (каталог `UtilitiesMenuCatalog` получает `RegisterExternal`,
  построители WPF/Avalonia вызывают `execute` для `CommandKind = External`).
- `AuditHub.Write(AuditEvent e)` — статическая точка: без модуля аудита — пустая;
  вызывается из удаления базы, загрузки CF, завершения сеансов, `--run` CLI, команд
  Telegram-бота, MCP-инструментов.
- `BackupUploadHooks` — список обработчиков «копия готова» (`IBackupUploader`): WebDAV
  в публичном коде, S3 — в модуле.
- `ScheduledTaskKind.Pipeline` — задание по расписанию, исполнитель регистрируется
  модулем через `SchedulerService.RegisterExecutor(kind, func)`.
