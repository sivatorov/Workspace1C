# Workspace 1C 1.0.1.113

Итоговый выпуск с четырьмя исправлениями: **#134**, **#143**, **#146**, **#153**.
Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

### #153 — одна база под разными учётными записями

Индикатор запуска, двойной щелчок и вкладка «Запущенные» больше не путают записи
одной базы, заведённые под разными учётными данными (авторизация ОС и имя/пароль).

- `RunningInfobaseMatcher.SelectOwnerForProcess` выбирает ровно одну запись на
  процесс: по `/N` — с совпадающим эффективным пользователем Предприятия
  (без учёта регистра, trim/кавычки), без `/N` — с авторизацией ОС или без явных
  учётных данных; при неоднозначности выбор детерминирован по ключу базы.
- `MatchProcesses` использует этот выбор; `FindDirectOwners` оставлен только для
  диагностики. Один процесс — максимум одна запись.
- `MainViewModel` передаёт эффективного пользователя с учётом общей авторизации;
  флаги `IsRunning`/`IsEnterpriseRunning`/`IsConfiguratorRunning` считаются по
  собственному списку процессов записи, а режим «Только запущенные» сравнивает
  состав по ключу базы, а не по `Id`.
- Активация существующего окна выполняется только для запущенной записи; окна
  перечисляются с фильтром по учётной записи. Щелчок по второй записи запускает
  новый экземпляр под её учётными данными, а на вкладке «Запущенные» одна
  запущенная база даёт одну строку.

### #146 — меню «Утилиты»

Пользовательские группы верхнего уровня сохраняются отдельными кнопками, режим
«С надписью» применяется к кнопке раздела, иконка группы едина в правке группы,
дереве, поле выбора и реальном меню. Старые компоновки мигрируют без потери
настроек.

### #143 — «Резервные копии средствами СУБД»

Окно больше не «зависает» на «Сохранить» и «Проверить…»: профиль и проверки
выполняются в фоне с реально работающими таймаутами и отменой, старые профили
нормализуются, окно остаётся отзывчивым.

### #134 — инспектор процессов

Первое `↓` сразу после открытия окна больше не уводит фокус на кнопку «Колонки»;
`↓` и `Ctrl+A` работают без клика мышью, фокус возвращается в таблицу после
завершения процесса.
