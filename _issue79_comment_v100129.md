**Исправлено в [v1.0.1.29](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.29)**

@7OH, диагностика показала: rac 8.5.4 в «infobase summary list» не отдаёт НИ ОДНОГО поля СУБД (dbms/db-server/db-name/db-user — пустые), а «infobase info» на вашей базе отвечает «Недостаточно прав пользователя» — собрать профиль СУБД для ibcmd программе попросту не из чего. Поэтому:

1. В мастере «Развернуть тестовую копию» появился блок **«Данные СУБД источника»** — включите «указать вручную», поля подставятся автоматически (тип/сервер — из целевых полей, имя БД — из Ref источника), поправьте при необходимости — и выгрузка через ibcmd пойдёт.
2. Сообщение об ошибке теперь прямо советует оба выхода: ручные данные СУБД источника ИЛИ движок «Конфигуратор» (пароль СУБД не нужен в принципе).
3. Заодно исправлено падение окна со стилем PasswordBox («TargetType TextBox…»).
