Здравствуйте, 7OH! Спасибо за уточнение — теперь понял: пометка должна быть только у разделов, а не у каждого файла.

Исправлено в версии **1.0.1.125** — [релиз v1.0.1.125](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.125).

**Причина.** В 1.0.1.124 суффикс « (раздел)» добавлялся к подписи каждого файла в списке, если раздел был определён, — вместо того чтобы оставаться только у названия раздела.

**Что изменено:**

- из подписи каждого файла убран суффикс « (раздел)»;
- пометка осталась только у названий разделов: в списке разделов и в заголовках групп (выделенных жирным/цветом);
- значения фильтра (какие файлы показываются при снятых галочках) не изменились;
- паритет WPF (Windows) и Avalonia (Linux), локализация ru/en;
- тесты `Issue167PlatformDownloadSectionTests`.

**Что проверить на 1.0.1.125:**

- в списке файлов у названий файлов нет « (раздел)»;
- пометка « (раздел)» видна только у разделов — в списке разделов и заголовках групп;
- фильтрация по разделу и разрядности работает как раньше.
