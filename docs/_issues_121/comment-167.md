Здравствуйте! Спасибо за замечание.

Исправлено в версии **1.0.1.121** — [релиз v1.0.1.121](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.121).

**Причина.** На странице загрузки платформы фильтр по разрядности применялся всегда и не отключался, а выбор раздела страницы загрузок отсутствовал — файлы разных разделов показывались вперемешку, и выбранный файл не сохранялся.

**Что изменено:**

- добавлена галочка «Только моя разрядность»: фильтрация x64/x86 выполняется **только при включённой галочке** (по умолчанию включена);
- добавлен выбор **раздела** страницы загрузок — галочка и `ComboBox`, видимые при наличии разделов (`HasSections`);
- выбор файла сохраняется между открытиями окна.

Паритет WPF/Avalonia, локализация ru/en. Тест: `Issue167PlatformDownloadSectionTests`.

**Что проверить на 1.0.1.121:**

- с включённой галочкой «Только моя разрядность» видны только файлы своей разрядности, без неё — все;
- выбор раздела показывает файлы выбранного раздела;
- выбранный файл сохраняется при повторном открытии окна.

Issue не закрываю — прошу подтвердить на 1.0.1.121 и написать здесь.
