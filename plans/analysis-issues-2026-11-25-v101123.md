### #167 — диалог скачивания платформы

Последние 4 комментария 7OH (20:24):

1. Галочка фильтра разрядности должна стоять **слева от заголовка поля**, без
   дополнительного текста («Только моя разрядность» и т.п. убрать) — только
   чекбокс рядом с подписью поля выбора файла.
2. **Поле выбора раздела не появилось вообще.** Разделы страницы загрузок —
   это сворачиваемые группы вида «Windows (64-bit)», «Linux (64-bit)» и т.п.
   Нужно исправить парсер страницы: определять разделы и показывать выбор.
3. Убрать из отображаемых имён файлов «добавки» вида «Полный клиент (rar)» —
   они часто не соответствуют содержимому (сервер/платформа/аддин).
   Оставить только разрядность (где она есть) и название раздела.
4. Логика отображения (в списке выбора файла):
   - без галочек: `Раздел - x64 - имя_файла`;
   - галочка разрядности включена, раздела нет: `Раздел - имя_файла`;
   - галочка раздела включена, разрядности нет: `x64 - имя_файла`;
   - обе галочки: `имя_файла`.
   То есть учитываемое (отфильтрованное) значение в строке не дублируется.
   Сортировать список по итоговому строковому представлению.

Затрагиваемые файлы (предварительно):

  формирование отображаемого имени, сортировка.

  парсинг разделов страницы, фильтрация, имя строки.

## Ограничения и порядок

1. Версия увеличивается **только последним числом** и **один раз** — после всех
   исправлений (`1.0.1.122` → `1.0.1.123`).
2. Каждый пункт выполняется **отдельной задачей**; issues не закрываются.
3. После каждого изменения — запись в `CHANGELOG.md` и `README.md`.
4. Собрать по одному исполняемому файлу: Windows (win-x64) и Linux (linux-x64),
   single-file self-contained.
5. Опубликовать коммит, тег и GitHub Release `v1.0.1.123`, продублировать новость
   в Telegram-канал `-1004425443528`.
6. В каждом issue после исправления — комментарий: что исправлено и в какой версии.
