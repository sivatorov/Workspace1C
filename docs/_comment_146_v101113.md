По комментарию от 2026-11-23T07:48:24Z:

1. **Одна иконка везде.** Правка группы, дерево редактора, поле выбора иконки и реальное меню теперь используют единый резолвер `UtilitiesMenuCatalog.WpfIconGeometryKey` (в редакторе — `UtilitiesIconOption.GeometryKey`). Особый PackIcon-путь для группы «Новинки программы» убран, нерезолвимый сохранённый ключ нормализуется к стандартной иконке группы. Иконка в настройке, в дереве и в меню совпадает на обеих платформах.

2. **«С надписью» применяется к кнопке панели.** Кнопки разделов/групп на верхней панели строятся через `UtilitiesMenuGroupPresentation`: при `ShowLabel = true` — иконка и подпись, при `false` — только иконка с подсказкой. Стандартные разделы по умолчанию компактны (вид панели не меняется), пользовательские группы верхнего уровня по умолчанию показываются с подписью. Вложенные группы всегда с подписью.

3. **Группа верхнего уровня больше не «переезжает» в «Утилиты».** В компоновку добавлены стабильный `NodeId` и признак `IsTopLevel` (схема файла — 5). Группа, созданная в корне, получает `IsTopLevel = true` и `NodeId`; миграция переносит пользовательские узлы в «Утилиты» только для старых схем (< 5) и не трогает явные группы верхнего уровня. После сохранения группа остаётся отдельной кнопкой, можно создать несколько групп верхнего уровня без ручной правки JSON. Старые файлы мигрируют один раз без потери настроек.

Кнопка каждой группы открывает именно её содержимое (по `GroupId` для стандартных разделов и по `NodeId` для пользовательских групп), панель перестраивается сразу после сохранения компоновки — без перезапуска.

Добавлены регрессионные тесты: сохранение/загрузка/миграция групп верхнего уровня, несколько групп, планировщик кнопок, открытие по `NodeId`, режим «С надписью» для кнопки панели и подменю, единый ключ геометрии иконок на всех поверхностях.
