Дополнение к 1.0.104: исправлен регресс с подписями групп в версии **1.0.1.105** (Windows/WPF и Linux/Avalonia) — [релиз v1.0.1.105](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.105).

В 1.0.104 режим отображения группы по умолчанию был «Иконка», поэтому разделы «Обновления», «Приложение», «Справка» и другие группы показывались только значками. Теперь:

- по умолчанию используется «С надписью» — в меню видны иконка и текст, как в остальных меню;
- компоновки, сохранённые 1.0.104 с явным `DisplayMode: "Icon"`, однократно мигрируются на подписи (схема 4);
- явный выбор «Иконка», сделанный в новой схеме, сохраняется;
- новые группы, создаваемые в редакторе, тоже по умолчанию идут с подписью.

Тесты: дополнен `Issue146UtilitiesMenuTests` (3 теста). Полный прогон: 7706 тестов, все зелёные.
