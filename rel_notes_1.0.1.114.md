# Workspace 1C 1.0.1.114

Выпуск с двумя исправлениями: **#154** (кнопка «Определить» и COM через
PowerShell 5.1) и **#146** (режим «С надписью» на панели «Утилит»). Релиз
доступен для **Windows** (WPF) и **Linux** (Avalonia).

## Исправлено

### #154 — кнопка «Определить» больше не падает с `0xC0000409` (Windows)

Сведения о конфигурации читаются через Windows PowerShell 5.1 (.NET Framework),
где COM-вызов `Connect` работает штатно, а не через агент на CoreCLR, который
обрывал процесс нативным fast-fail.

- при нативном fast-fail агента (`0xC0000409`, `0xC00000FD`, `0xC0000005`,
  `0x80000003`) и при `noprogid` чтение автоматически повторяется через
  PowerShell;
- при `noprogid` перебираются разрядности 64 → 32 бита (SysWOW64);
- запрос передаётся через stdin в Base64 — пароль не попадает в командную строку;
- диагностика показывает ProgID, версию платформы, использованный хост и
  разрядность, а также подсказку о регистрации `comcntr.dll` в нужной
  разрядности; новые ключи локализации добавлены в `ru.json` и `en.json`.

### #146 — переключатель «Иконка» / «С надписью» снова работает (Windows и Linux)

- панель «Утилит» строится по сохранённой пользовательской компоновке даже при
  выключенном режиме правки — сохранённый `DisplayMode` теперь доходит до кнопок;
- фиксированные 32×32 в стилях `IconButton` заменены стилем `SectionLabelButton`
  (WPF и Avalonia), подпись кнопки не обрезается;
- вложенные группы всегда отображаются с подписью.
