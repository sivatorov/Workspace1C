# Workspace 1C 1.0.1.9

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).
Скачать: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.9

### Исправлено / Добавлено

- **Мастер «Развернуть тестовую копию»: убрана кнопка-дубль «Учётные данные ИБ для
  ibcmd…» внизу окна (issue #79, Windows и Linux).** По последнему комментарию 7OH
  кнопка дублировала блок «Данные для выгрузки через ibcmd» и кнопку «Свойства
  исходной базы» вверху окна — удалена из WPF- и Avalonia-версий мастера
  ([`TestDeployWindow.cs`](Workspace1C/Views/TestDeployWindow.cs),
  [`TestDeployWindow.Avalonia.cs`](Workspace1C/Views/TestDeployWindow.Avalonia.cs));
  связанные ключи локализации вычищены.

- **Мастер «Развернуть тестовую копию»: кнопка «Подставить из профиля СУБД» вместо
  дублирующих профиль полей (issue #79, Windows и Linux).** По аналогии с кнопкой
  «Подставить из базы» (логин/пароль выгрузки) добавлена кнопка «Подставить из
  профиля СУБД…» рядом с полями СУБД: заполняет поля формы (тип, сервер, база,
  пользователь, пароль) из профиля исходной базы окна «Резервные копии СУБД»;
  при отсутствии профиля — подсказка. Поля остаются редактируемыми вручную
  («либо данные из профиля, либо вручную»).

- **Мастер «Развернуть тестовую копию»: операция выполняется по значениям на форме;
  разовый сценарий без сохранённого профиля проходит валидацию (issue #79, Windows
  и Linux).** Поля СУБД формы передаются в ibcmd как переопределение параметров
  подключения ([`TestDeployService.cs`](Workspace1C/Services/TestDeployService.cs),
  [`IbcmdService.cs`](Workspace1C/Services/IbcmdService.cs)); пред-валидация
  ([`TestDeployPlanner.cs`](Workspace1C/Services/TestDeployPlanner.cs)) теперь
  принимает ЛИБО сохранённый профиль СУБД, ЛИБО заполненные поля СУБД на форме —
  разовая копия без постоянного профиля разворачивается без ошибки «заполните
  профиль». Тексты подсказок (`TestDeploy.NeedDbmsProfile`,
  `TestDeploy.IbcmdCredentialsHint`) обновлены.

### Тесты

- [`Issue79TestDeployWindowTests.cs`](Workspace1C.Tests/Issue79TestDeployWindowTests.cs):
  отсутствие удалённой кнопки-дубля и её ключей локализации; наличие кнопки
  «Подставить из профиля СУБД»; подстановка полей из профиля (`AutofillDbmsFromProfile`);
  пред-валидация ibcmd без сохранённого профиля при заполненных на форме полях СУБД
  и с пустыми полями — понятная ошибка; значения полей формы попадают в сценарий.
