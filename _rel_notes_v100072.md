# Workspace 1C 1.0.0.72

Релиз доступен для **Windows** (WPF) и **Linux** (Avalonia).

### Добавлено

- **Конфигуратор параметров запуска: правка, порядок и поиск пользовательских
  параметров (issue #68, Windows и Linux)** — окно «Запустить с выбором параметров»:
  кнопка **«Изменить»** открывает отдельный диалог правки параметра; кнопки
  **«Вверх/Вниз»** меняют порядок пользовательских параметров в справочнике; поле
  **поиска** фильтрует список по ключу и описанию. Пользовательские параметры стали
  доступны и на Linux. Покрыто тестами `LaunchParametersCatalogTests`.

- **Подстановки для сценариев: все реквизиты базы и диалог «Выбрать переменную»
  (issue #67, Windows и Linux)** — справочник токенов расширен (`%connection.user%`,
  `%connection.type%`, `%connection.port%`, `%id%`, `%имягруппы%`); резолвер понимает
  логин/пароль, которые реально подставит стартер (включая общую авторизацию);
  добавлена кнопка **«Выбрать…»** с диалогом всех переменных базы (поиск, вставка по
  «Ок» и двойному клику, пароли маскируются). Покрыто тестами
  `ScriptTokenPickerViewModelTests`.

### Изменено

- **«Публикация на веб-сервере» перенесена в контекстное меню базы (issue #63,
  Windows и Linux)** — пункт теперь в подменю **«Администрирование»** (над «Историей
  запусков»); парсер конфигов Apache разбирает **DocumentRoot** и **Listen**; URL
  публикации учитывает порт (`http://localhost:8027/…`). Покрыто тестами
  `WebPublishIssue63Tests`.

- **Редактор меню трея: перемещение блоков в пользовательскую группу (issue #62,
  Windows и Linux)** — добавлены кнопки **«В группу…»** (диалог выбора подменю) и
  **«В корень»**; блоки/разделители переносятся в пользовательскую группу и обратно.
  Покрыто тестами `TrayMenuGroupMoveTests`.

- **Миграция баз: пользователь СУБД берётся из исходной базы (issue #41, Windows и
  Linux)** — rac отдаёт db-user в «infobase summary list», поэтому он используется с
  приоритетом, значение диалога — fallback. Покрыто тестами
  `ClusterMigrationServiceTests`.

### Исправлено

- **Остатки тёмной темы: окно «Изменение сервера» (issue #61, Windows и Linux)** —
  заголовки полей и заголовок окна на Linux снова не читались — привязаны к
  `TextPrimaryBrush`; поле показа пароля на Windows переведено на стиль темы
  `ModernTextBox`. Тест-стражи `Issue61TitleColorsTests` расширены.

Подробности — в [CHANGELOG.md](https://github.com/sivatorov/Workspace1C/blob/main/CHANGELOG.md).
