Исправлено в версии **1.0.1.6** (Windows и Linux):

Скачанный файл обновления теперь валидируется по магическим байтам платформы перед применением: Linux-сборка обязана быть ELF (`7F 45 4C 46`), Windows — PE (`MZ`)
([`UpdatePayload.ValidatePlatformMagic`](Workspace1C/Services/UpdatePayload.cs)). Неподходящий бинарник (например Windows-EXE у «застрявшей» старой версии) не применяется: файл переименовывается в `*.wrong-platform` (карантин для диагностики), решение пишется в журнал, а пользователь получает понятную ошибку с подсказкой скачать сборку `Workspace1C-linux-x64` и установить вручную.

Дополнительно добавлена диагностика выбора ассета: имя и размер выбранного ассета релиза пишутся в журнал по диагностическому флагу `CM_UPDATES`
([`GitHubReleaseService.FindAsset`](Workspace1C/Services/GitHubReleaseService.cs)).

Если автообновление с версии ≤ 1.0.1.3 не доезжает — установите **1.0.1.6 вручную**, скачав сборку для своей платформы (`Workspace1C.exe` для Windows, `Workspace1C-linux-x64` для Linux). Все последующие обновления будут проходить автоматически.

Релиз: https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.6
