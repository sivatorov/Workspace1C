@7OH, по четырём пунктам:

1. «Срок действия» — в формате `dd.MM.yyyy HH:mm:ss`, без AM/PM (когда время есть в файле).
2. Колонка «Пользователей» — теперь заполняется из «Количество пользователей» файла (парсер стал устойчивее к реальному формату файла).
3. Окно просмотра лицензии очищено: длинный начальный ключ и «шапка» файла убраны — остались строка «Файл лицензии» и поля в том виде, как в файле.
4. Колонки «Пользователь»/«Состояние» берутся из вывода ring; если поля нет — пустая ячейка (источник данных указан в подсказке заголовков колонок).
