Здравствуйте, 7OH! Спасибо за сравнение раскладок Windows и Linux — замечание по делу.

Исправлено в версии **1.0.1.120** — [релиз v1.0.1.120](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.120).

**Причина.** В Windows блок «Доля цвета папки» находился после редактора цветов, а в Linux — сверху; паритет между оболочками был нарушен, и в Windows блок было легко не найти.

**Что изменено:**

- в Windows блок «Доля цвета папки» перенесён наверх;
- порядок теперь одинаковый в обеих оболочках: тема → доли цвета → цвета;
- поведение слайдеров, привязки и сохранение настроек не изменились.

Паритет WPF/Avalonia, локализация ru/en. Тесты: `Issue161GroupColorTintOrderTests`.

**Что проверить на 1.0.1.120:**

- в Windows блок «Доля цвета папки» расположен над блоком цветов;
- слайдеры и сохранение значений работают как раньше.

Issue не закрываю — прошу подтвердить на 1.0.1.120 и написать здесь.
