Доработано в версии **1.0.1.121** — [релиз v1.0.1.121](https://github.com/sivatorov/Workspace1C/releases/tag/v1.0.1.121).
Базовое открытие редактора меню по ПКМ было выпущено в **1.0.1.120**; в 1.0.1.121 исправлены иконка, зона клика и раскрыватель.

**Причина.** Иконка узла строилась по ключу, которого не было в наборе, и откатывалась к чужой иконке; кликабельной была только часть строки, а раскрыватель занимал отдельную узкую зону.

**Что изменено:**

- иконка узла строится по геометрическому ключу (`DisplayIconGeometryKey`, цвет через `FromSpec`);
- вся строка узла кликабельна: прозрачный фон, `Cursor=Hand`, обработчик ПКМ на строке;
- раскрыватель растянут на всю строку в темах Avalonia и WPF.

Тест: `Issue159UtilitiesContextMenuTests`.

**Что проверить на 1.0.1.121:**

- правый клик по любому месту строки узла открывает контекстное меню;
- иконка узла отображается в текущей теме;
- раскрыватель растянут на строку и срабатывает по клику.
