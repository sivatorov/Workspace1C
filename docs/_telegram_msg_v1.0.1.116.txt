🚀 Workspace 1C 1.0.1.116 — обновление выпущено

Что исправлено (issue #146):
• Окно «Правка контекстного меню»: пояснение вынесено из зоны прокрутки — теперь как в остальных трёх редакторах, прокручивается только панель операций.
• Высоты окон правки меню: «Утилиты» — 825, «Мои программы» — 760, «Меню трея» — 855, «Контекстное меню» — 685. Окна открываются сразу на минимально необходимой высоте, кламп по рабочей области сохранён.
• Пункты и разделители можно вынести на верхний уровень панели инструментов: пункт отображается кнопкой-иконкой с подсказкой, разделитель — вертикальной чертой; порядок сохраняется в компоновке.
• «Инспектор процессов 1С» стал обычным пунктом меню «Утилиты» и по умолчанию размещён на верхнем уровне; кнопка и её разделитель убраны с панели, горячая клавиша Ctrl+Alt+I сохранена.

Проверка: полный прогон — 7999 тестов, 0 падений, 0 пропущено.

Доступны сборки для Windows и Linux — один файл, установка .NET не требуется.
